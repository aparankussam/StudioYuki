# Studio Yuki Arts

Marketing site for **studioyukiarts.com** — warm, patient piano lessons for kids
ages 5–13 in Troy, Michigan.

- **Framework:** Next.js 14 (App Router), deployed on Vercel
- **Content:** editable via `/admin` (Vercel Blob) with template fallbacks in `templates/`
- **Booking:** Formspree lead capture with text-message fallback

## Develop
```bash
npm install
npm run dev
```
